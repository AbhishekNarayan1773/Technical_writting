Google Docs

Introduction

Google Docs is a free, web-based word-processing application developed by Google. It allows users to create, edit, format, and collaborate on documents online.

It supports real-time collaboration, automatic saving, comments, version history, and document sharing.

Objectives

* Understand the Google Docs interface.
* Create and format professional documents.
* Work with tables, images, links, and page layouts.
* Use headers, footers, and page numbers.
* Collaborate with multiple users.
* Use comments and suggestions.
* Download and export documents in different formats.

Topics Covered

1. Introduction to Google Docs
2. Creating and Managing Documents
3. Text Formatting and Paragraph Styling
4. Page Setup and Layout
5. Tables, Images, and Hyperlinks
6. Headers, Footers, and Page Numbers
7. Collaboration and Sharing 
8. Comments and Suggesting Mode
9. Version History
10. Exporting and Downloading Documents

Practical Applications

Google Docs is useful for:

* Preparing technical reports.
* Writing academic assignments.
* Creating project documentation.
* Collaborating on group assignments.
* Preparing resumes and professional documents.
