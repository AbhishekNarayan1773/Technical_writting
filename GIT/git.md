Git

Introduction

Git is a free and open-source distributed version control system used to track changes in source code and manage software development projects.

It allows developers to maintain different versions of their projects, collaborate with team members, and revert to previous versions whenever required.

Objectives

* Understand the fundamentals of Git.
* Install and configure Git.
* Learn basic Git commands.
* Create and manage repositories.
* Track changes in files.
* Understand commits, branches, and merging.
* Work with remote repositories.
* Resolve merge conflicts.
* Understand the Git workflow.

Important Git Commands

Command	Description
git --version	Checks the installed Git version
git config	Configures Git settings
git init	Initializes a repository
git status	Displays the working tree status
git add	Stages changes
git commit	Saves staged changes
git log	Displays commit history
git branch	Manages branches
git checkout	Switches branches or restores files
git merge	Merges branches
git clone	Copies a remote repository
git pull	Fetches and integrates remote changes
git push	Uploads local commits to a remote repository
git fetch	Downloads remote updates
git stash	Temporarily saves uncommitted changes
git tag	Manages version tags

Applications of Git

* Software development and source code management.
* Team collaboration.
* Tracking project history.
* Maintaining multiple development versions.
* Managing open-source projects.
* Continuous integration and deployment workflows.
